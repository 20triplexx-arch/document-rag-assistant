### 技术栈与数据流

Python 3.12 + FastAPI/Uvicorn；前端为原生 HTML/CSS/JavaScript，无构建步骤。教材索引及账号/讨论使用 SQLite，生成服务使用 DeepSeek。

```text
资料准备：固定来源 → 下载与版本/哈希核对 → 按章节分块 → 持久索引
学习提问：账号会话与讨论所有权检查 → 按教材检索 → 本轮原文证据
只查原文：证据 → 保存本用户记录 → 展示来源与片段（不调用模型）
生成讲解：证据 → 事务预留调用额度 → DeepSeek → 结构与引文出处核对 → 保存本用户记录 → 展示
```

一次讲解最多调用一次模型；没有检索证据时不调用模型。引文出处检查核对本轮证据与原文，不证明结论得到支持。

## DeepSeek 配置

继续读取现有 `DEEPSEEK_API_KEY` 环境变量，型号读取 `DEEPSEEK_MODEL`，未设置时使用代码默认型号。不回退到其他服务商。启动进程必须能继承这些变量，PyCharm 可在运行配置中继承或设置。
