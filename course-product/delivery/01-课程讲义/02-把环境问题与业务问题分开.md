# 第02课 把环境问题与业务问题分开

模块：认识 Agent | 建议用时：阅读25分钟 + 动手20分钟

## 学习目标

建立独立 Python 环境；辨认当前工作目录；理解环境变量和配置文件的区别。

## 中文讲解

一个脚本能运行，至少有三项条件：解释器存在、导入的模块存在、读取的数据路径正确。先从终端检查 Python 版本，不要在看到 ImportError 时就反复修改业务代码。三个练习只使用 Python 标准库，因此无需安装 Agent 框架、数据库客户端或向量库；SQLite 模块已经随常见 Python 安装提供。

解压后进入“03-练习项目”，建立独立虚拟环境。创建环境只是在本机放置一套解释器和包目录，不会替你配置云端模型。Windows 可直接使用虚拟环境的 python.exe，无需调整执行策略，也无需激活环境。路径带空格时用引号包住。

联网配置从当前终端的环境变量读取。目录中的 .env.example 只是变量名称示例，程序不会自动读取它；把真实密钥写进去也不会让脚本自动生效。变量作用于当前终端及其子进程，关闭终端后本次配置通常就结束。课程包不包含可使用的密钥。

> 流程：解压目录 → 解释器版本 → 独立环境 → 离线命令 → 可选联网配置

数据路径同样重要。记忆项目默认把数据库写到当前工作目录的 runtime；文档问答的默认示例目录则相对于脚本位置定位。学习排错时，记录执行命令、工作目录、Python 版本和错误类型四项信息，先定位是哪一层失败。

## 示例与观察

Windows PowerShell：
```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe tool_agent.py
```
macOS/Linux使用python3与./.venv/bin/python，按相同步骤创建环境。
本包验收环境为 Windows / Python 3.12。其他系统命令供配置参考，未作同等实机验收。

## 动手任务

建立环境并运行计算示例。记录解释器路径，然后从另一个目录运行 document_qa.py，解释为什么默认示例资料仍能被找到。

## 参考答案

虚拟环境解释器在 .venv 下。文档目录使用 Path(__file__).resolve().parent 定位，取的是脚本所在目录，不是终端当前位置。memory_chat 的相对 --db 路径则取决于当前位置；需要固定位置时显式传入 --db。

## 常见问题

问：python 命令不存在怎么办？答：先安装官方 Python 3.12，或在 Windows 用 py -3.12；把命令中的 python 替换为实际解释器路径。

问：能复用现有项目的环境吗？答：可以，但独立环境更容易确认没有依赖被旧项目悄悄补齐，优先用独立环境验收。
