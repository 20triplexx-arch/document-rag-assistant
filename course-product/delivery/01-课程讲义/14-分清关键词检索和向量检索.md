# 第14课 分清关键词检索和向量检索

模块：文档问答 | 建议用时：阅读25分钟 + 动手20分钟

## 学习目标

解释两种检索的匹配依据；用同义问题观察关键词基线的局限。

## 中文讲解

关键词检索比较问题与文档中的词。课程基线提取英文单词和中文连续二字片段，再用重叠数量排序。它容易解释：你能指出哪些字词贡献了匹配；但不理解完整语义，“报销凭证”与“费用材料”未必能稳定匹配。

向量检索先把文本转换成一组数字，再比较问题向量与文档向量。它可能召回表达不同但语义相近的片段，也可能召回词义相近但业务无关的资料。向量模型不是事实判断器，相似度高不表示文档回答了问题。

同一个索引的文档向量与查询向量必须使用兼容的嵌入模型和处理方式。更换模型后，通常需要重新生成索引，不能只改查询侧配置。维度相同也不证明两个模型的向量空间相同。

> 流程：关键词比较词项；向量比较嵌入表示；两者都要查相关性

先保留关键词基线，准备包含精确术语、同义表达、无答案的问题，再比较改进。课程不内置向量服务，向量与混合检索的实现参考案例手册，不把当前代码称为向量 RAG。

## 示例与观察

在配套项目里对比：
```powershell
python document_qa.py "报销材料有哪些？"
python document_qa.py "费用申请要准备哪些凭证？"
python document_qa.py "量子纠缠的数学定义是什么？"
```
第二题可能不如第一题稳定，第三题应返回没有相关资料。

## 动手任务

为一个产品说明文档写三道精确术语题、三道同义题和两道无答案题，保存预期证据位置。

## 参考答案

例：精确题“保修期限是多少”，同义题“坏了多久内能免费修”，无答案题“竞争品牌保修多久”。预期证据应指向真实文档；无答案题应注明没有对应证据，而不是给一个编造的位置。

## 常见问题

问：关键词分数能叫置信度吗？答：不能，它只是重叠词项数，没有校准成正确概率。

问：向量检索一定更好吗？答：要看题型和数据，精确编号、代码符号等常常仍需要词项匹配。
