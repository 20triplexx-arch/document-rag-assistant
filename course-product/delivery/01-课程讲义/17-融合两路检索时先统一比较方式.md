# 第17课 融合两路检索时先统一比较方式

模块：RAG 优化 | 建议用时：阅读25分钟 + 动手20分钟

## 学习目标

理解混合召回、去重和排名融合；避免直接相加不可比较的分数。

## 中文讲解

关键词擅长精确词项，向量擅长相近语义，混合检索希望覆盖两类问题。通常先各取候选，再按片段 ID 去重，最后融合或重排。不是把两个完整答案拼在一起，而是先融合证据候选。

两路分数可能处于不同尺度。一个是词项相关分，一个是余弦相似度，直接相加会让数值较大的那一路主导。可先使用基于名次的融合，例如每个候选从各路获得 1/(k+rank)，再累加。rank 从 1 开始，k 是平滑常数。

融合后仍要控制重复信息。同一段文档在两路都出现时应作为一个来源，而不是把它算成“两份独立证据”。相邻重复片段也会挤占上下文，应按事实覆盖检查。

> 流程：词项召回 + 向量召回 → ID 去重 → 融合排名 → 候选证据

用固定题集比较词项、向量与混合方法，尤其看精确编号与同义表达的差别。记录原始排名和最终排名，才能解释某条证据为何上升或下降。课程基础代码不包含这个融合算法，下面是独立的教学小实验。

## 示例与观察

基于名次融合：
```python
def fuse(rankings, k=60):
    scores = {}
    for ranking in rankings:
        for rank, item in enumerate(ranking, 1):
            scores[item] = scores.get(item, 0) + 1 / (k + rank)
    return sorted(scores, key=scores.get, reverse=True)
print(fuse([["A", "B"], ["B", "C"]]))
```
B 在两路均被召回，一般排到更靠前。

## 动手任务

为编号查询与同义查询各造一份两路排名，运行 fuse，解释结果。

## 参考答案

编号题的关键词第一名可能最可靠；同义题向量第一名可能更有帮助。融合只是排序方法，仍须检查证据是否回答问题。两路同时排前不代表来源独立或结论正确。

## 常见问题

问：混合一定比单路慢很多吗？答：要测实际检索与服务耗时，不能仅凭算法名称判断。

问：平滑常数60是通用最优值吗？答：它是常见实验起点，需用自己的题集验证。
