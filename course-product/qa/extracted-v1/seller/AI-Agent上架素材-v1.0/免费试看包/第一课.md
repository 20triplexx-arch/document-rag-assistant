# 第01课 用三个小作品建立学习路线

模块：认识 Agent | 建议用时：阅读25分钟 + 动手20分钟

## 学习目标

能把“学 Agent”拆成可以检查的结果；知道聊天、工具调用、记忆和文档问答各解决什么问题。

## 中文讲解

你会一点 Python，最容易遇到的困难通常不是不会写函数，而是不知道模型、工具和数据应该怎样连接。先给自己一个明确的终点：让程序完成一项任务，并留下能回查的过程。本课程用三个练习建立这条路径：计算工具展示执行，SQLite 展示状态保存，文档问答展示证据来源。

聊天模型接受消息并生成下一条消息。Agent 在此基础上增加行动：模型提出调用某个工具，程序验证参数，执行工具，再把结果交回模型。模型说“已经计算”不代表计算发生；你需要看到函数实际返回的结果。会话记忆解决重启之后数据还在不在，RAG 解决回答之前有没有找到外部资料。它们可以组合，但不是同一种能力。

学习时采用“先执行，再观察，再修改”的顺序。第一遍运行默认离线示例，排除网络、余额和模型波动。第二遍阅读关键函数，解释输入如何变成输出。第三遍只改变一个变量，例如把除数改成零，观察失败结果。能说明失败原因，比只展示一张成功截图更能证明你理解了程序。

> 流程：输入任务 → 程序状态 → 工具或资料 → 可检查的输出

每个作品都应有验收证据。计算助手记录 operation、a、b 和结果；记忆项目用两个独立进程验证恢复；文档问答显示文件名、行号和原文。课程中的三个练习是教学实现，不提供公网账号、浏览器自动化或生产环境保证。

## 示例与观察

在“03-练习项目”目录依次运行：
```powershell
python tool_agent.py --operation multiply --a 18 --b 7
python memory_chat.py --session learner --message "我在学 RAG"
python document_qa.py "报销材料有哪些？"
```
第一个输出 126；第二个创建本地会话；第三个输出原文摘录及来源。默认运行均不请求模型。

## 动手任务

为三个作品各写一句验收条件，必须包含输入、预期行为和检查方法。然后写出你最想替换的真实学习任务。

## 参考答案

示例：输入 18×7，calculate 返回 126，并能在 observation 中查看；连续运行两次记忆程序，第二次输出包含第一次输入；问报销材料，sources 指向报销规则中的材料段落。真实任务可以是“从自己的产品说明里查退换条件”，先用虚构或公开资料测试。

## 常见问题

问：必须先学深度学习数学吗？答：本课程主要讲应用程序的数据流，先掌握函数、字典、JSON、终端命令即可。

问：离线运行也算模型 Agent 吗？答：离线模式验证程序结构，不具有模型自主决策能力。联网工具循环才让模型选择工具，两者的输出会明确标注。
