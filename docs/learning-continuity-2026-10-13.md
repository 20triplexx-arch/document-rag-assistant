# 连续学习、讲解重点与取证性能

日期：2026-10-13（Asia/Shanghai）。本轮围绕继续优化功能、质量和内容开展，不推送 GitHub，不改动课程产品的已有修订。

## 已交付

- 当前讨论支持连续追问，例如先问 RAG 与记忆，再问“这个怎么实现”。服务端检查用户和讨论所有权后，只读取最多 12 条尾部记录，选择最近四轮成功讲解或原文检索记录；问题与回答摘要合计最多 6000 字符。失败记录不成为主题。
- 追问检索只继承上一轮主题，独立新问题不拼入历史；长追问不截断当前问题，连续多次“继续讲”保持原主题。切到单套资料时只使用同一筛选范围的历史；“联系本讨论”可以关闭。跨讨论和跨用户不读取历史。
- 历史摘要作为 JSON 数据发送，只帮助理解当前问题；系统要求历史回答未经支持验收、不能作为事实证据，不能沿用旧引用编号。事实与引文仍核对本轮证据。没有前文的简单追问返回 `CONTEXT_REQUIRED`，不调用模型，保留输入并提示补充主题。
- `explanation_style` 支持 `deep`、`practice`、`compare`。实战重点要求前提、输入输出、步骤、检查与失败恢复；比较重点要求双方来源、选择条件和缺口。没有实现代码证据时不能编造可运行代码。默认深入讲解，输出预算、日额度和每题一次模型请求保持原规则。
- 回答后的“讲透原理 / 看实战步骤 / 比较方案”只填入问题和讲解重点，由用户点击提问；不自动请求，也不覆盖未发送草稿。首页示例补充工具循环、规划与上下文、多 Agent 与可观测性。
- 引用标题去除 HTML/Markdown 展示标记，证据正文、位置和链接保持原文。界面保持白色布局、逐轮证据定位与手机适配。

网页开启联系本讨论后，生成请求会把上述本人讨论摘要发送给 DeepSeek；只查原文仍不发送任何模型请求。响应只记录轮数、主题和版本，不再次复制整个上下文。新的参数纳入请求去重检查；旧记录仍可显示，数据库无需迁移。

CLI 的独立试答也可选择重点（该命令会调用真实模型，不属于本轮验收）：

```powershell
.\.venv\Scripts\python.exe starter.py ask '工具调用如何检查参数和执行结果？' --style practice
```
