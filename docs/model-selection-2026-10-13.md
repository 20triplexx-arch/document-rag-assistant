# 按次提问选择 DeepSeek 模型

日期：2026-10-13（Asia/Shanghai）。用户要求增加模型选择。

## 使用与范围

学习首页输入框下的“AI 模型”可选 DeepSeek Flash (`deepseek-flash`) 和 DeepSeek Pro (`deepseek-v4-pro`)。默认沿用服务端 `DEEPSEEK_MODEL`，未设置或为空时使用 Flash。已配置的旧型号名称保留为兼容选项；正常当前配置提供两种官方型号。

同一页面内切换讨论、提交问题和失败恢复保留当前选择；刷新页面重新采用服务端默认。每次提问独立选择，不修改其他用户或全局默认。回答会显示实际响应型号，缺少用量中的型号时显示本次所选型号。旧历史保持兼容，不补造历史型号。

2026-10-13，官方模型接口 HTTP 200，当前密钥可访问 Flash 和 Pro。两者仍使用专用 DeepSeek Key、固定官方域名、JSON 输出、8192 token 上限、120 秒超时、每题最多一次请求和零自动重试。日调用次数与并发限额共用原规则；Pro 失败不会自动调用 Flash。当前 [官方费率](https://api-docs.deepseek.com/quick_start/pricing/) 中 Pro 高于 Flash，选择项已注明费用较高；没有声称本轮验证了 Pro 更准确或更深入。

“只查原文”禁用模型选择并保持零生成请求。管理诊断工作台继续使用服务端默认型号，本次没有修改实验型号配置。

CLI 独立试答支持显式型号（运行此命令会调用真实模型）：

```powershell
.\.venv\Scripts\python.exe starter.py ask 'RAG 与长期记忆有什么区别？' --model deepseek-v4-pro --style compare
```

## 接口与隔离

- `/api/library` 保留原 `model` 字段，增加 `default_model` 和 `models`（ID、显示名、说明、默认标记）；不返回密钥。
- `/api/ask` 增加可选 `model`，省略时采用默认型号。仅允许服务端已注册的型号，未知型号返回 422，拒绝发生在额度预留和生成之前。
- 请求结果保存 `requested_model` 和 `selected_model`，使用实际响应的 `usage.model` 标明型号；同一请求编号改变模型返回 409。旧记录缺少新字段时仍支持默认请求复用。
- 每种型号有独立生成对象，按本次请求选择；不修改共享默认对象的型号。注入测试模型时只提供指定替身，避免测试意外调用真实 API。
- 前端兼容只提供旧 `model` 字段的服务；服务不提供新选项清单时不提交新增请求字段。切换型号不触发调用。
