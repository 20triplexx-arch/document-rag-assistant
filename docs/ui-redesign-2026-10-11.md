# 白色聊天工作区重设计

验证日期：2026-10-11，Asia/Shanghai。

采用用户批准的白色聊天方向，使用 Impeccable 检查交互、状态和可访问性，design-taste-frontend 检查排版和模板化装饰。保留学有据标识、本机中文字体和已有操作蓝，中性灰服务导航、字段和原文；移除大号欢迎文案、胶囊例题、教材卡片网格和重复书本图标。没有引入框架、远程字体、图片或运行时依赖。

## 页面行为

- 桌面侧栏 232px（1100px 以下 208px），阅读宽度最多 800px；760px 以下顶部导航和可展开历史。正文 16px，空讨论标题 26px。
- 空讨论先显示输入、范围与模式。有结果后，同一个表单固定在底部；测量实际输入区高度给正文留足滚动空间。新讨论恢复空状态。
- 五个集合由接口生成紧凑资料行，显示篇数与“已选”。课程重复点击恢复全部，案例行打开目录并选中范围；案例快捷按钮支持匿名浏览且保留当前问题、范围。
- 编号按讨论轮次绑定对应原生 details，保留固定版本原文与行号入口。“引用已核对”继续配有“引用核对不代表答案正确”。
- 目录、登录注册、管理员概览采用相同控件与间距。英文标记、主题、许可、实现链接与长路径仍可读。
- 请求显示“检索中”或“生成中”，锁定本轮问题、范围与模式。网络、额度、模型或引文检查失败保留输入；不自动重试模型。

